# DH101

Jaylyn's DH 101 Spring 2026 portfolio: class makes, reflections, and a growing CV.

## Preview the website

Open `index.html` in a browser to view the portfolio. The site is a static page and does not require a build step or dependencies. Use the button in the navigation to switch between light and dark themes; your choice is saved in the browser.

The makes section links to the weekly project notes in `makes/`. Update those Markdown files as projects take shape, and add education, experience, skills, and selected projects to the CV section in `index.html`.

For Markdown help, see [pages/markdown-guide.md](pages/markdown-guide.md).
